# form_automation

**Pipeline role: Application API.** The final stage of `Data -> Hybrid Search -> Application Generator -> Application Controller -> Application API` — the actual submission call to the ATS. Fires only once `review_gate/` approves, either automatically or after the user approves via the review email.

Per-ATS-type form-filling (not per-company). Reads a form's fields, maps them to the profile store, fills them. Every answer comes from Python's output, bridged in via Go — this service never reads `source_of_truth/` itself: deterministic fields (visa, salary, EEO, etc.) are taken by Python straight from `source_of_truth/`'s structured fields, free-text/behavioral fields are generated by `tailoring/`.

**Language: TypeScript** — shared singleton service, not one per ATS instance, called by every Go orchestrator instance. Likely browser automation (Playwright-style) for JS-heavy application forms.
