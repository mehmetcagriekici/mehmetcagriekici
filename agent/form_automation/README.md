# form_automation

**Pipeline role: Application API (decided 2026-07-22).** The final stage of `Data -> Hybrid Search -> Application Generator -> Application Controller -> Application API` — the actual submission call to the ATS. Only fires once `review_gate/` (the Application Controller) approves, either automatically (passes its honesty/relevance check) or after the user approves via the review email.

Per-ATS-type form-filling (not per-company). Reads a form's fields, maps them to the profile store, fills them. Deterministic fields (visa, salary, EEO, etc.) are filled directly from `source_of_truth/` structured data; free-text/behavioral fields are generated by `tailoring/` (Python) and bridged in via Go — see `../tailoring/README.md`.

**Language: TypeScript.** Runs as one shared singleton service (not one per ATS instance) called by every Go orchestrator instance — see tech stack in `../README.md`. Likely browser automation (Playwright-style) for JS-heavy application forms.
