\section{Projects}

\project{BlightSanest --- Stable Insights \normalfont(in development)}{May 2026 -- Present}{Go, Python, gRPC, PostgreSQL/pgvector, Redis, S3, Docker, AWS}
Privacy-first smart journaling platform: users store personal data across any domain and query it conversationally through RAG or directly through hybrid search.
\begin{itemize}
  \item Architected three services --- Go API orchestrator, Python RAG engine, Go pub/sub --- communicating over gRPC, with per-user isolated indexes for privacy by design.
  \item Implemented hybrid retrieval: BM25 and semantic embeddings (Sentence Transformers, pgvector) fused with Reciprocal Rank Fusion; Ollama for local LLM, AWS Bedrock in production.
  \item Built pre-computed indexing pipeline with S3 as source of truth, Redis hot cache with automatic fallback, MessagePack serialization, and Alembic schema migrations.
  \item RAG service phase complete; production design targets Aurora Serverless, EKS, and Cognito with a full Docker Compose local stack. \hfill \href{https://github.com/mehmetcagriekici/blightsanest_stable_insights}{\faGithub\ repo}
\end{itemize}

\project{AI Damage-Claim Verification Agent}{June 2026}{Python, CLIP, Ollama, Docker}
24-hour hackathon (HackerRank Orchestrate, June 2026). Multimodal pipeline that decides whether submitted images support, contradict, or insufficiently evidence damage claims across cars, laptops, and packages.
\begin{itemize}
  \item Combined CLIP (clip-ViT-L-14) image--text similarity for damage type, severity, and image-quality classification with a local Llama 3.2 model (Ollama) producing validated 14-field structured verdicts.
  \item Designed modular agent architecture (vision RAG layer $\rightarrow$ context organizer $\rightarrow$ LLM reasoner) with tunable evidence thresholds calibrated against labeled sample data. \hfill \href{https://github.com/mehmetcagriekici/hackerrank-orchestrate-june26}{\faGithub\ repo}
\end{itemize}

\project{Reargs Similarity API \normalfont(live demo)}{Aug 2025 -- Mar 2026}{Python, FastAPI, ChromaDB, Sentence Transformers, Gemini}
Semantic document-analysis API that detects patterns, redundancies, and similarities across uploaded documents (.txt, .md, .pdf).
\begin{itemize}
  \item Automatic clustering via vector embeddings, natural-language querying of similar content, and LLM-powered generation from selected clusters.
  \item Deployed with a live public demo; GitHub Actions CI runs tests on every push; multi-stage Docker build. \hfill \href{https://github.com/mehmetcagriekici/reargs}{\faGithub\ repo}
\end{itemize}
